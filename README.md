# Нормативный бот РТ для Telegram

Это стартовый проект Telegram-бота для поиска нормативных документов Республики Таджикистан.

## Возможности
- Главное меню Telegram с кнопками.
- Поиск по шифру, названию, области применения и ключевым словам.
- Каталог по разделам проектирования.
- Выбор типа объекта.
- Карточка документа со статусом, областью применения, частями, пунктами и ссылкой на источник.
- SQLite-база; импорт исходных карточек из CSV при первом запуске.

## Важно о достоверности
В комплекте находится только начальный реестр. Некоторые карточки помечены «Требует проверки».
Числовые требования (ширины, площади, высоты, расстояния, нагрузки и т. п.) нельзя добавлять без проверки полного действующего текста нормы и её приложений.
Не считайте этот стартовый каталог полным официальным реестром нормативов РТ.

## 1. Создать Telegram-бота
1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте `/newbot`.
3. Задайте имя и username бота.
4. Скопируйте токен. Не публикуйте его и не отправляйте посторонним.

## 2. Установить и запустить
Требуется Python 3.10 или новее.

### Windows
```powershell
cd normativny_bot_rt
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
python bot.py
```

### Linux / сервер
```bash
cd normativny_bot_rt
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
python bot.py
```

После запуска откройте своего бота в Telegram и отправьте `/start`.

## 3. Добавить нормативы
Откройте `data/norms.csv` в Excel или редакторе таблиц.
Добавляйте строки, соблюдая заголовки колонок:
- `code` — шифр документа;
- `title` — название;
- `category` — категория из каталога;
- `status` — «Действующий», «Утратил силу» или «Требует проверки»;
- `approval` — реквизиты утверждения;
- `effective_date` — дата введения;
- `scope` — область применения;
- `parts` — части и приложения;
- `clauses` — пункты, таблицы и проверенные значения;
- `source_url` — ссылка на официальный источник;
- `notes` — примечания;
- `keywords` — слова для поиска.

После первоначального запуска CSV импортируется в SQLite один раз. Чтобы повторно импортировать обновлённый CSV, остановите бота, удалите файл `data/norms.db` и запустите снова. Это пересоздаст базу из CSV.

## 4. Размещение 24/7
Для постоянной работы бот должен запускаться на компьютере, VPS или другом сервере, который не выключается.
Не размещайте токен в публичном репозитории. Используйте переменную окружения `TELEGRAM_BOT_TOKEN`.

## 5. Что нужно для полноценной нормативной версии
1. Полные официальные тексты документов РТ в PDF/DOC.
2. Проверка статуса каждого документа по ADLIA и органу утверждения.
3. Разметка пунктов, таблиц и страниц.
4. Связи «тип объекта → раздел проекта → нормативный пункт».
5. Регулярная проверка изменений законодательства.
